# RECIPE FINDER APP - PALATE PLANNER

This Capstone project was developed as part of my Front-End Development program at ALX Africa. It’s a recipe finder application with a unique twist, users can search for recipes, view detailed instructions, and save their favorite recipes to plan for special occasions. The app was built using React.js for the front-end, styled with a combination of Vanilla CSS and TailwindCSS, and is deployed on Vercel for hosting.

## Functions 
* Search Function - Helps users Find recipes using an ingrediant or name of a particular dish.
* Filter - User's are able to search by recipe category eg. Seafood or Breakfast.
* Recipe Details - User's are able to access and view recipe detail on a page that contains details such as ingrediants, measurements and instructions.
* Favourites page - User's are able to save their favourite recipes and access them and their details whenever they want.
### Future Features
* Planner - A page that allows's users to create a meal plan for any reason including planned ocassions or just for weekly meal prep. This planner opens into a an individual plan where a user's can search ad add recipes to their plans, write notes and create shopping lists.
* Dark & Light theme - To provide users whith an option to change the theme to suite their lighting preferences.
